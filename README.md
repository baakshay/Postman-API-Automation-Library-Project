# 🚀 API Automation Framework: Library Management System

This repository demonstrates a robust API Automation Framework built using **Postman**, **Newman**, and **Jenkins**. It features data-driven testing, environment management, and a complete CI/CD pipeline integration.

---

## 📌 Project Overview
The goal of this project is to automate the end-to-end testing of Library Management APIs (**Add, Get, and Delete books**). It ensures that the API is reliable, scalable, and bug-free through continuous validation.

## 🛠 Tech Stack
* **Testing Tool:** Postman
* **CLI Runner:** Newman
* **Environments:** Postman Environments (QA & UAT)
* **Data-Driven Testing:** CSV Data Files (`booksData.csv`)
* **CI/CD:** Jenkins
* **Scripting:** JavaScript (Postman Sandbox)

## 🔍 Premium Framework Features
* **Data-Driven Testing:** Utilizes `booksData.csv` to run the same test suite against multiple data sets automatically.
* **Dynamic Variable Handling:** Implemented **Global, Environment, and Collection variables** for seamless data flow between requests.
* **Complex Assertions:** * Status Code validations (200 OK).
    * Response body property checks (e.g., "book is successfully added").
    * Header validation (Content-Type checks).
    * Response time performance testing.
* **Request Chaining:** Automatically captures the `ID` from the 'AddBook' response and passes it to 'GetBook' and 'DeleteBook' requests using variables.

## ⚙️ How to Run This Project

### 1. Prerequisites
* Install [Node.js](https://nodejs.org/)
* Install Newman using NPM:
    ```bash
    npm install -g newman
    ```

### 2. Execution via CLI
Navigate to the project folder and run the following command:
```bash
newman run Library.postman_collection.json -e QA.postman_environment.json -d booksData.csv

🔄 CI/CD Implementation (Jenkins)
I have integrated this framework into a Jenkins CI/CD Pipeline to enable automated testing on every code commit.

Setup Steps:
Node.js Plugin: Configured in Jenkins Global Tool Configuration.

Newman Installation: Handled via Jenkins 'Execute Shell' using npm install -g newman.

Build Script:

Bash
newman run Library.postman_collection.json -e QA.postman_environment.json -d booksData.csv -r cli,html --reporter-html-export reports/index.html
Artifacts: Jenkins is configured to archive the HTML reports generated by Newman for audit and analysis.

📊 Reporting
CLI Reports: Real-time execution summary in the Jenkins console/terminal for quick debugging.

HTML Reports: Detailed visual reports showcasing passed/failed assertions and response details for stakeholders.
